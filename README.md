# Food Quality & Sales BI

**Food Quality & Sales BI** — BI-проект, моделирующий работу пищевой FMCG-компании.

Цель проекта — объединить данные о продажах, производстве, качестве продукции и клиентских рекламациях и исследовать, как показатели качества влияют на финансовый результат компании.

В рамках проекта будет построен интерактивный дашборд в Power BI для анализа продаж, прибыльности продукции, производственных показателей, уровня брака и рекламаций.

Особое внимание уделяется связи качества и коммерческих результатов: продукт может показывать высокую выручку, но одновременно создавать значительные потери из-за брака, возвратов и компенсаций.

> **Project status:** In progress

## Project Goal

Проект должен помочь ответить на вопросы:

- какие продукты и категории формируют основную выручку;
- какие товары имеют высокие продажи, но низкую маржинальность;
- как меняются продажи во времени;
- какие регионы и каналы продаж показывают лучшие результаты;
- на каких производственных площадках выше уровень брака;
- какие виды дефектов встречаются чаще всего;
- какие продукты получают больше всего рекламаций;
- как брак, возвраты и компенсации влияют на финансовый результат компании.

## Dataset

В проекте используются синтетические данные, созданные для моделирования работы пищевой FMCG-компании.

Данные включают информацию о:

- продуктах и категориях;
- продажах;
- регионах и каналах продаж;
- производственных площадках;
- производственных партиях;
- результатах контроля качества;
- браке продукции;
- клиентских рекламациях;
- возвратах и компенсациях.

Планируемая модель данных включает следующие таблицы:

| Table | Description |
|---|---|
| `dim_product` | продукты, категории и характеристики SKU |
| `dim_date` | календарные данные |
| `dim_region` | регионы продаж |
| `dim_channel` | каналы продаж |
| `dim_plant` | производственные площадки |
| `fact_sales` | продажи по продуктам, датам, регионам и каналам |
| `fact_production` | данные о производственных партиях |
| `fact_quality` | результаты контроля качества и дефекты |
| `fact_complaints` | клиентские рекламации, возвраты и компенсации |
