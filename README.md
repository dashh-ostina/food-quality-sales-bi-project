# Food Quality & Sales BI

**Интерактивный Power BI-дашборд для анализа продаж, прибыльности, производства и качества продукции FMCG-компании.**

Проект выполнен на синтетических данных и демонстрирует навыки моделирования данных, разработки DAX-метрик, визуализации и бизнес-анализа.

## Технологии

**Power BI · Power Query · DAX · Data Modeling · Python (генерация данных)**

## О проекте

Разработан аналитический отчёт из четырёх страниц:

1. **Продажи и финансы** — динамика выручки, прибыль, маржинальность, анализ товарных категорий.
2. **Региональный анализ** — выручка, прибыль и доля регионов в продажах.
3. **Производство и качество** — объёмы выпуска, доля брака, переработка и анализ видов дефектов.
4. **Обращения клиентов** — структура жалоб, их серьёзность, статусы и доля закрытых обращений.

Модель включает 9 связанных таблиц и интерактивные фильтры.

## Основные выводы

- **Beverages** обеспечивает наибольшую выручку (33,05%), но имеет минимальную маржу среди категорий (45,46%).
- **Snacks** — наиболее маржинальная категория (52,13%).
- **Москва, Московская область и Санкт-Петербург** формируют около 62% общей выручки.
- **Тульская площадка** имеет самую высокую долю брака — 1,39%.
- **Packaging** — наиболее распространённый вид зарегистрированных дефектов (3 139 событий).
- **Packaging / leakage** — самая частая причина клиентских обращений (830 жалоб).

Результаты позволяют выделить направления для дальнейшего исследования качества и эффективности бизнеса.
